# Software Release Lifecycle

Software is typically released in several stages before becoming a stable product.

---

## Development Stages

```text
Idea
  ↓
Prototype
  ↓
Alpha
  ↓
Beta
  ↓
Release Candidate (RC)
  ↓
Stable / General Availability (GA)
  ↓
Maintenance
```

---

# Prototype

A prototype is an early proof of concept.

Characteristics:

- Demonstrates an idea
- Not feature complete
- Often built quickly
- May never become a real product

Best for:

> Validating ideas.

---

# Alpha

An **Alpha** version is an early development release.

Core features are usually implemented, but the software is still under active development.

Characteristics:

- Many bugs may exist
- Features may be incomplete
- User interface may change
- Performance may not be optimized
- Data formats may change
- Not recommended for production use

Think of Alpha as:

> **"The software works, but it is still being built."**

---

# Beta

A **Beta** version is much closer to the final product.

Most major features have been completed.

Characteristics:

- Feature complete (or nearly complete)
- Fewer bugs than Alpha
- Wider public testing
- Focus on stability and usability

Think of Beta as:

> **"The software is mostly finished and is being tested by users."**

---

# Release Candidate (RC)

A Release Candidate is a version that is expected to become the final release unless major bugs are found.

Characteristics:

- Feature complete
- Very stable
- Only critical bug fixes are expected

Think of RC as:

> **"If nothing serious is discovered, this will become the official release."**

---

# Stable (General Availability)

A Stable release is intended for everyday users.

Characteristics:

- Fully tested
- Stable
- Suitable for production
- Regular bug fixes and security updates

Think of Stable as:

> **"Ready for normal use."**

---

# Summary

| Stage | Description | Recommended for Daily Use |
|--------|-------------|---------------------------|
| Prototype | Proof of concept | ❌ |
| Alpha | Early development | ❌ |
| Beta | Public testing | ⚠️ Usually |
| RC | Nearly final | ✅ Most cases |
| Stable / GA | Official release | ✅ |

---

# Key Takeaways

- **Prototype** → Prove an idea.
- **Alpha** → Core functionality exists but development is ongoing.
- **Beta** → Feature complete and focused on testing.
- **RC** → Final testing before release.
- **Stable / GA** → Official version for everyday users.

---

| Label | Meaning |
|--------|---------|

| Beta | Public testing |
